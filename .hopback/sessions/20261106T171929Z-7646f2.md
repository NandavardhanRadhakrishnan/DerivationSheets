- Edit endpoints require a loopback `Host` header; `httptest.NewRequest` defaults to `example.com`, so tests set `r.Host = "localhost:8080"`.
- T-19's description says the editor needs no change, but `SheetRefs` fills `uses` from every expression on a formula row; an input row with a reject naming other inputs has no `uses` field today, so check how graph dependencies should come from an input row's reject `when` (graph.Build only reads an input's own `when`).

- Python edits on Windows: open files with `encoding='utf-8'` (templates contain non-ASCII) and keep line endings as found.
