## Gotchas
- **The safety check blocks a sandbox reset.** Claude Code's safety check refuses `rm -rf /d/pm-test` and `setup.sh` (it deletes remotes/, work/ and .bin/). The developer has to run the reset themselves: `! rm -rf /d/pm-test && cd /d/projects/acme-corp && bash setup.sh`.
- **Fixture edits need formatting.** `TestRepositoryFilesAreFormatted` checks the test fixtures as well, so run `go run ./cmd/dsheets fmt` after editing any committed fixture TOML.
- **Shared fixture.** The requirements tests copy `../agree/testdata/shop`, so changing that fixture affects both packages.
- **Numbers are float64.** Compare values with `sheet.Equal`, never `==` on interface values.
- **Scratch probes.** To probe dsheets behaviour without touching the tree, `git archive HEAD` into the scratchpad and patch the copy. That's how the `freeShipping` checks were confirmed in the replay.
- **Before tests or merges, restore `specs/`** with `git checkout -- specs/`.
- **Uncommitted `.hopback/` changes.** The parking writes leave `.hopback/` changes uncommitted on `boundary-agreement`. Stash them with `--include-untracked` when switching branches, as HOPBACK.md says.
