## Gotchas

- **Restore `specs/` before tests or merge, without asking** (`git checkout -- specs/`). The validator tests read `specs/order-checkout` from the working tree.
- **Navigating away with Playwright** while the editor has unsaved changes opens a `beforeunload` dialog, and the page stays on the old build. Accept it, or check that the page's inline scripts contain your new code, before trusting results.
- **Stopping the test server:** `taskkill //IM dsheets.exe` with a filter matched nothing. Kill by the PID from `netstat -ano | grep 127.0.0.1:8731`. Don't kill the developer's own `serve`.
- **"close pr" was ambiguous;** the developer meant merge. Ask when a phrase could mean discarding work.
- CSS and JS are embedded (`go:embed`): rebuild and restart `serve` after editing them.
- Python on Windows: open files with `newline=''` to keep line endings.
- `gh pr merge --delete-branch` switches to `main` and pulls; stash `.hopback` around it.
- Hopback task status for finished work is `completed`. Work on a branch in the main checkout; no git worktrees.
