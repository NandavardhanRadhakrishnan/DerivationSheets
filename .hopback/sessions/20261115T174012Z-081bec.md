## Gotchas
- **Interfaces must be matched by declared name** (`iface.Interface.Name`), as `flow.Connect` does. The PM's flow and a team's own flow refer to the same interface by different paths (`orders:interfaces/order-placed.toml` versus `../../interfaces/order-placed.toml`).
- **Use wire values, not row values.** A `send.map` turns row values into codes on the wire, so expected and fed values must be what is sent.
- **`eval.Evaluate` rejects with `MISSING_INPUT` when a `call.<stage>.<field>` input has no value.** The plan adds `eval.Pending` so calls can be resolved in passes.
- **`cases.toml` is generated.** Hand edits are only allowed for `"?"` values, which depend on text rules.
- **Acme's sheets don't declare an interface.** None sets `request_schema` or `target_schema`. A team's own flow is the only thing that links its sheet to its boundaries.
- **Before tests or merges, restore `specs/`** with `git checkout -- specs/`. Stash `.hopback/` with `--include-untracked` when switching branches.
- **Windows line endings.** Some files are CRLF in the worktree (autocrlf), so run `gofmt -l` before committing.
