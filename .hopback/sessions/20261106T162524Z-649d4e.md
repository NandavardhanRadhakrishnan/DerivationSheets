## Gotchas

- The working tree is CRLF on Windows (`core.autocrlf=true`), although the repository stores LF. Tests run every example in LF, CRLF and no-final-newline forms; keep that when adding writer tests.
- Editing Go files with a Python script in text mode on Windows writes CRLF, which made `gofmt -l` flag the file. Run `gofmt -w` after scripted edits, or use the Edit tool.
- tomledit matches keys by name and sub-tables by name and position. Only a `*Table` from `Parse` keeps its original span. Replacing a row with a freshly built `&Table{}` makes it a new span: its comments are dropped and it is rewritten in full. M2's `ApplyRow` must change the parsed table in place.
- Numbers compare by value (`int64(0)` equals `0.0`), so JSON floats from the browser do not count as changes.
- `go test ./...` takes about two minutes, mostly `internal/impact` and `internal/sources` with git fixtures. Run the touched packages first.
- The executing-plans ledger for this plan is in `.superpowers/sdd/2026-11-06-visual-editor/progress.md` (git-ignored, local only). It records the rulings and deferred minors. Keep using it for tasks 5–16.
