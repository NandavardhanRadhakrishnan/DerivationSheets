## Gotchas

- **Restore `specs/` before tests or merge, without asking** (`git checkout -- specs/`): the developer tries the editor on `specs/order-checkout`, and its saves (version bump, cases.toml) break tests that read the working tree. Developer's rule, 2026-11-07; replaces the old "ask before reverting".
- Python on Windows writes CRLF in text mode; gofmt then lists the file. Use `open(p, newline='')` or `sed -i 's/\r$//'`. Git Bash `grep -c $'\r'` does not show the CRs; use `od -c`.
- `gh pr merge --delete-branch` switches the checkout to `main` and pulls; stash `.hopback` after it, then pop.
- CSS and JS are embedded (`go:embed`): rebuild and restart `serve` after editing them.
- Hopback task status for finished work is `completed`, not `done`.
- Work on a branch in the main checkout; no git worktrees.
- Playwright screenshots go under `.playwright-mcp/` (git-ignored). Serve on `127.0.0.1:<port>`, not `localhost`.
- Don't pipe into a bare `cat >` with no input in Bash; it waits on stdin until timeout.
