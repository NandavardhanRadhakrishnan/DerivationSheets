## Gotchas

- **Restore `specs/` before tests or merge, without asking** (`git checkout -- specs/`).
- Test edits in a throwaway clone (`git clone -q . <scratchpad>/repo`, serve from there) so saves don't touch the real `specs/`.
- Playwright: navigating away with unsaved edits raises a `beforeunload` dialog; accept it. Playwright screenshots must be saved under the repo (`.playwright-mcp/`), not the scratchpad.
- Stop test servers by PID from `netstat -ano | grep "127.0.0.1:8731 .*LISTENING"`; the background task then reports "failed", which is expected.
- In this shell, `cat > file` with no heredoc waits on stdin; a long heredoc piped to `python -` once failed to parse. Write patch scripts with the Write tool and run them.
- CSS and JS are embedded: rebuild and restart `serve` after editing them. Python edits: open with `encoding='utf-8', newline=''`.
- Case IDs follow results, so an edit can rename a case; compare cases by `key` (input), not ID.
- A check (`/edit/check`) takes ~330 ms on order-checkout, mostly `cases.Generate`.
