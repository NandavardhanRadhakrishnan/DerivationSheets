## Objective

T-16: keep the sheet page's table header (with the grid's line numbers) visible while scrolling, on every sheet page (`render`, `serve`, `serve --edit`), and check print and phone width.

## Done

- **Merged:** PR #5, merge commit `ee156b2` on `main` (commit `bbf51e7`); CI green (test, GitGuardian). `go test ./...`, `go vet ./...` and gofmt clean locally. Branch `sticky-grid-header` deleted locally.
- `internal/render/sheet.css`: `.sheet thead th` is `position: sticky; top: 0; z-index: 2` with `background: var(--bg)`. The rule under the header is `box-shadow: inset 0 -1.5px 0 var(--line-strong)` (`border-bottom: 0`), because a collapsed border does not move with a sticky cell.
- Same file, `@media (max-width: 900px)`: `.sheet` was `overflow-x: auto`, which makes the table the scroll container for its own sticky header. It is now `overflow: auto; max-height: 100vh / 100dvh`, so it scrolls both ways inside its box and the header sticks.
- Same file, `@media print`: `.sheet` gets `max-height: none`, and the header goes back to `position: static` with a real border; `thead` still repeats on each page.
- `internal/render/editor.css`: `@media screen and (max-width: 900px)` caps `body.editing .sheet` at `100dvh - var(--ed-bar)` so the box ends at the fixed bar. It must stay `screen`-only: it is more specific than the print reset, and an earlier version left a 712px cap on printed pages.
- `examples/sheet.html` re-rendered with `dsheets render specs/order-checkout --out examples/sheet.html`. It also picked up an older snapshot-line wording change ("design-time data in data/, updated ...").
- Checked in Playwright on `specs/order-checkout` with `serve --edit`: desktop light and dark (header at top 0 after scrolling), 390px wide scrolled both ways (header pinned, box ends at the bar, no horizontal page scroll), print media (static, repeating header, no cap).
